# Images

The images endpoints generate an image from a text prompt and edit or compose existing images.

- [Generate an image](https://dev.meta.ai/docs/api-reference/images/create-image)
- [Edit an image](https://dev.meta.ai/docs/api-reference/images/edit-image)
- [Schemas](https://dev.meta.ai/docs/api-reference/images/schemas)

For prompts, multi-turn editing, reference images, and worked examples, see the [Image generation](https://dev.meta.ai/docs/image-generation) feature page.
