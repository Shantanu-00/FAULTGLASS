# Files

The files endpoints upload files for use in inference requests and manage previously uploaded files.

- [Upload a file](https://dev.meta.ai/docs/api-reference/files/upload-file)
- [List files](https://dev.meta.ai/docs/api-reference/files/list-files)
- [Retrieve a file](https://dev.meta.ai/docs/api-reference/files/retrieve-file)
- [Retrieve file content](https://dev.meta.ai/docs/api-reference/files/retrieve-file-content)
- [Delete a file](https://dev.meta.ai/docs/api-reference/files/delete-file)
- [Schemas](https://dev.meta.ai/docs/api-reference/files/schemas)

For supported file types, upload examples, and how to reference files in requests, see the [Files](https://dev.meta.ai/docs/file-handling) feature page.
