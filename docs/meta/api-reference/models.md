# Models

The models endpoints list the models available through the Meta Model API and retrieve metadata for a single model.

- [List models](https://dev.meta.ai/docs/api-reference/models/list-models)
- [Retrieve a model](https://dev.meta.ai/docs/api-reference/models/retrieve-model)
- [Schemas](https://dev.meta.ai/docs/api-reference/models/schemas)

For a catalog of available models, capabilities, and context windows, see the [Models](https://dev.meta.ai/docs/models) page.
