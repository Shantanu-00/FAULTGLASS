# Voice

The audio endpoints transcribe speech to text. Transcribe a complete recording in one request, or stream live audio over a WebSocket and receive transcripts as the audio arrives.

- [Transcribe a recording](https://dev.meta.ai/docs/api-reference/voice/transcribe)
- [Transcribe in realtime](https://dev.meta.ai/docs/api-reference/voice/realtime)
- [Schemas](https://dev.meta.ai/docs/api-reference/voice/schemas)

For modes, speaker labels, endpointing, and worked examples, see the [Speech to text](https://dev.meta.ai/docs/speech-to-text) feature page.
